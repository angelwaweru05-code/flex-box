# Angel Chelsey Waweru - Portfolio

A responsive personal portfolio website showcasing projects, skills, and contact information.

## Features

- **Responsive Design** - Works on desktop, tablet, and mobile
- **Smooth Scrolling Navigation** - Fixed header with smooth scroll to sections
- **Project Showcase** - Grid layout displaying 6 projects with tech stacks
- **Contact Section** - Email, phone, location, and social media links
- **Modern UI** - Clean design with CSS animations and hover effects

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript

## Project Structure

```
portfolio1/
├── index.html      # Main HTML file
├── style.css       # Stylesheet
├── js/
│   └── js.js       # JavaScript file
├── hero.jpeg       # Hero section image
└── background.jpg  # Background image
```

## Sections

1. **Hero** - Introduction with profile image
2. **About** - Background and aspirations
3. **Projects** - 6 project cards with tech tags
4. **Contact** - Contact info and social links

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. No build steps or dependencies required

## Customization

- Replace `hero.jpeg` with your profile image
- Update project details in `index.html`
- Modify colors in `style.css` (primary: `#9D00FF`)
- Update contact info and social links in `index.html`
